Data rules

Aggressor side: Binance aggTrade m=true means buyer is maker, so the taker sold. m=false means taker bought.

Hot flow: this browser seeds only the most recent public events, then accumulates WebSocket data while the tab is open. Selecting 4h/8h/12h does not claim that much history unless coverage actually exists.

Weekly VP: generated by GitHub Actions from Binance Vision daily USD-M aggTrades ZIP files. The build verifies Binance's SHA-256 checksum and aggregates reported executed quantity at $1 price bins. The page re-bins those rows for display.

No orders, API keys, account permissions, liquidation reconstruction or order-book heatmap.

Research prototype. The page always shows actual captured coverage and does not fabricate missing history.
